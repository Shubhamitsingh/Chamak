## 🎯 For Each Product (Repeat 12 Times)

### **Step 1: Click "Create product"**
- [ ] Clicked "Create product" button
- [ ] Selected "One-time product"

### **Step 2: Fill Basic Info**
- [ ] **Product ID:** `coins_90` (lowercase, underscore, no spaces)
- [ ] **Product Name:** `90 Coins` (what users see)
- [ ] **Description:** `Purchase 90 coins for your Chamak wallet.` (minimum 4 chars)

### **Step 3: Set Price (CRITICAL!)**
- [ ] Found "Default price" section OR country table
- [ ] Set price: **₹9.00** (or your price)
- [ ] See green checkmark ✅ next to price

### **Step 4: Save**
- [ ] Scrolled to bottom
- [ ] Clicked **"Save as draft"** (NOT "Activate" yet)
- [ ] Saw confirmation: "Product saved" or "Draft saved"
- [ ] No error message

### **Step 5: Activate**
- [ ] Went back to product list
- [ ] Opened the product
- [ ] Clicked **"Activate"**
- [ ] Status changed to: ✅ **"Active"**

## ⚠️ If You See "Couldn't Save" Error

**Check these:**

1. [ ] Product ID filled? (must be unique)
2. [ ] Product Name filled? (minimum 1 char)
3. [ ] Description filled? (minimum 4 chars)
4. [ ] Price set? (at least one country)
5. [ ] Browser cache cleared? (Ctrl+Shift+Delete)
6. [ ] Internet connection stable?

**Then try:**
- [ ] Refresh page (F5)
- [ ] Try different browser
- [ ] Wait 5 minutes and retry
