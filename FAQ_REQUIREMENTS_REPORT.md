## 📱 App Features Analysis

### **Core Features Identified:**

1. **Live Streaming**
   - Host can start live streams
   - Viewers can watch live streams
   - Live chat during streams
   - Viewer list and count

2. **Dual Coin System**
   - **U Coins**: User's wallet balance (spendable)
   - **C Coins**: Host earnings (earned from gifts/calls)
   - Conversion: 1 U Coin = 5 C Coins

3. **Gift System**
   - 6 gift types (Rose, Heart, Diamond, Crown, Sports Car, Rocket)
   - Costs U Coins to send
   - Host receives C Coins

4. **Private Calls**
   - Viewer can request private call with host
   - Costs 1000 U Coins per minute
   - Host earns 5000 C Coins per minute

5. **Wallet & Payments**
   - Purchase U Coins
   - View U Coins balance
   - Withdraw C Coins (minimum 1000 coins for fiat, 5 USDT for crypto)

6. **My Earnings**
   - Shows C Coins earned from gifts/calls
   - Separate from wallet balance

7. **Social Features**
   - Follow/Unfollow users
   - 1-to-1 private chat
   - User profiles
   - Search users

8. **Account Management**
   - Phone authentication
   - Profile editing
   - Account settings
